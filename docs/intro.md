Descripción General

La plataforma Museo de Arte Moderno de Barranquilla es una solución web interactiva diseñada para acercar el arte y la cultura a niños, jóvenes y visitantes mediante experiencias digitales innovadoras. El sistema permite explorar información sobre el museo, visualizar obras artísticas, interactuar con contenido multimedia y utilizar herramientas basadas en Inteligencia Artificial para transformar imágenes en creaciones artísticas inspiradas en diferentes estilos.

2. Planteamiento del Problema
¿Qué problema se identificó?

Muchos visitantes, especialmente niños y jóvenes, tienen poco acceso a experiencias culturales interactivas y digitales dentro de los museos tradicionales.

Además, existe una baja integración entre el arte y las nuevas tecnologías, limitando la participación activa de los visitantes.

Solución Propuesta

Desarrollar una plataforma web moderna que combine:

Información cultural.
Interacción multimedia.
Inteligencia Artificial.
Experiencias digitales educativas.

3. Objetivos
Objetivo General

Desarrollar una plataforma web interactiva para el Museo de Arte Moderno de Barranquilla que integre tecnologías digitales e Inteligencia Artificial para mejorar la experiencia de los visitantes.

Diseñar una interfaz moderna y accesible.

5. Metodología de Desarrollo.

El proyecto nació a partir de la necesidad de acercar el arte y la cultura a las nuevas generaciones mediante herramientas tecnológicas innovadoras. Durante una investigación sobre experiencias digitales en museos, se identificó que muchos visitantes jóvenes interactúan más fácilmente con plataformas digitales que con métodos tradicionales de aprendizaje.

A partir de esta observación surgió la idea de desarrollar una plataforma web para el Museo de Arte Moderno de Barranquilla que permitiera a los usuarios explorar contenido artístico de manera interactiva e incorporar herramientas de Inteligencia Artificial para estimular la creatividad.

Fase 1: Investigación.

La primera etapa consistió en analizar diferentes sitios web de museos nacionales e internacionales para identificar buenas prácticas de diseño, navegación y experiencia de usuario.

Durante esta fase se estudiaron aspectos como:

Organización de galerías virtuales.
Experiencias interactivas para visitantes.
Uso de inteligencia artificial en el ámbito cultural.
Tendencias actuales de diseño web.

La información recopilada sirvió como base para definir los requisitos del sistema.

Bocetos.
Referencias.
Investigación del museo.
Fase 2: Diseño

Una vez definidos los objetivos, se elaboraron los primeros bocetos de la plataforma.
Se diseñó una interfaz moderna, intuitiva y visualmente atractiva que permitiera a los usuarios acceder fácilmente a la información del museo y a las herramientas disponibles.
Durante esta fase se definieron:
Estructura de navegación.
Distribución de contenido.
Paleta de colores.
Componentes visuales.
Diseño adaptable para diferentes dispositivos.

Fase 3: Desarrollo

El desarrollo del proyecto se realizó utilizando tecnologías web modernas.
Se construyeron los diferentes módulos de la plataforma, incluyendo:
Página principal.
Sección informativa del museo.
Galería de obras.
Panel administrativo.
Herramientas de Inteligencia Artificial.
Formularios de interacción.
Cada módulo fue desarrollado y probado individualmente antes de integrarse al sistema completo.

Integración de Inteligencia Artificial

Uno de los principales objetivos del proyecto fue incorporar funcionalidades basadas en Inteligencia Artificial.

Se desarrolló una solución que permite transformar imágenes en estilos artísticos digitales, ofreciendo a los visitantes una experiencia interactiva y creativa inspirada en las obras del museo.

Esta funcionalidad busca incentivar el interés por el arte mediante el uso de tecnologías emergentes.

Control de Versiones

Para garantizar una adecuada gestión del proyecto se utilizó GitHub como plataforma de control de versiones.

Mediante GitHub fue posible:

Registrar cambios en el código.
Gestionar versiones del proyecto.
Coordinar el trabajo colaborativo.
Mantener un historial completo del desarrollo.
Pruebas del Sistema

Una vez finalizado el desarrollo, se realizaron pruebas funcionales para validar el correcto funcionamiento de cada módulo.

Las pruebas permitieron verificar:

Navegación entre páginas.
Funcionamiento de formularios.
Integración de componentes.
Experiencia de usuario.
Compatibilidad con diferentes dispositivos.

Los resultados obtenidos fueron satisfactorios y permitieron corregir pequeños detalles antes del despliegue final.

Despliegue y Publicación

Con el proyecto terminado, se procedió al despliegue en un servidor web para hacerlo accesible desde internet.

Posteriormente se adquirió un dominio personalizado y se configuraron los registros DNS necesarios para conectar el dominio con la plataforma de alojamiento.

Como resultado, el sistema quedó disponible públicamente mediante:

josedev.site
panel.josedev.site
